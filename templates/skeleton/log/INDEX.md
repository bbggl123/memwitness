# Memory Log Index

> Quick navigation to raw memory log files in memory/log/.
> Each log file is append-only and never edited.
> Corrections are recorded as new entries tagged [override].

---

## YYYY-MM

| Date | Entries | Topic |
|------|---------|-------|
| YYYY-MM-DD | N | Brief topic description |

---

- Open directly: `memory/log/YYYY-MM-DD.md`
- Each entry is one line: `[HH:MM] tag: Content`
- Tags: `[stated]` (user said), `[observed]` (Agent noticed), `[decided]` (user chose), `[learned]` (new knowledge)
